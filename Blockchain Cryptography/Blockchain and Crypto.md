# Blockchain & Cryptography

## The First Primitive: Blockchain and Crypto

This section introduces the core concepts of **Blockchain**, **Cryptography**, and **Ethereum**. It explains why blockchain technology was created, how it establishes trust in decentralized systems, and why cryptographic hash functions are fundamental to blockchain security.

## Key Takeaways

- Blockchain enables decentralized trust without intermediaries.
- Smart contracts execute code transparently and securely on the blockchain.
- Cryptographic hash functions provide data integrity, security, and efficient verification.
- Hashing is a fundamental building block for blockchain consensus and transaction validation.
