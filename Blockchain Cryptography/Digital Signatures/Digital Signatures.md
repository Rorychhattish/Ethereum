# Supplemental Resources on Digital Signatures

This section contains additional learning resources to strengthen the understanding of **Public Key Cryptography**, **Digital Signatures**, and their applications in blockchain technology.

## ECDSA (Elliptic Curve Digital Signature Algorithm)

ECDSA is the digital signature algorithm used by Ethereum and Bitcoin. It provides strong security with smaller key sizes and is based on elliptic curve cryptography.

### Topics to Explore

* How ECDSA works
* Digital signature generation and verification
* Elliptic curve mathematics
* Why Ethereum uses the secp256k1 curve

---

## Bitcoin Address Generation

Bitcoin derives wallet addresses from a public key through multiple cryptographic operations.

Useful concepts to study:

* Private Key → Public Key
* Public Key → Hash
* Address Generation
* Base58 Encoding
* Checksum

Understanding this process also helps in learning how Ethereum derives addresses from public keys.

---

## Diffie–Hellman Key Exchange

Diffie–Hellman enables two parties to establish a shared secret over an insecure network.

Important concepts:

* Public Key Exchange
* Shared Secret Generation
* Hybrid Cryptography
* TLS/HTTPS Handshake

---

## RSA Cryptography

RSA is one of the earliest public key cryptography algorithms and is still widely used for secure communication and digital signatures.

Key concepts:

* Prime Number Factorization
* Public & Private Keys
* Encryption
* Decryption
* Digital Signatures

---

## Blockchain Relevance

Public Key Cryptography is the foundation of blockchain security.

It is used for:

* Wallet Generation
* Transaction Signing
* Signature Verification
* User Authentication
* Ownership Verification
* Secure Peer-to-Peer Communication

Ethereum and Bitcoin both rely on **ECDSA (secp256k1)** to authenticate transactions and prove ownership of digital assets.
